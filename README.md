# Egg Slayer 3D

A fan-made, Eggy Party style 3D obstacle race with demon-slayer style eggs. One static page, no build step.

- 14 characters built as 3D eggs, double jump, speed-boost roll, super start
- Touch controls and automatic landscape mode on phones, keyboard on desktop
- Solo races against computer rivals (online rooms only work in the Claude-hosted version)

## Controls
- Move: WASD / arrows, or the on-screen stick
- Jump: Space / Z / J (tap twice for a double jump)
- Roll boost: Shift / E / X / K
- Press F to show an FPS readout; use the GRAPHICS button if it lags

## Run locally
Open `index.html` in a browser (needs internet for three.js from cdnjs), or serve the folder with any static server.
